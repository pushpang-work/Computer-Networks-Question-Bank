## Question 

Describe the OSI model and the responsibility of each of its seven layers.

## Answer 

The OSI (Open Systems Interconnection) Model is a 7-layer conceptual framework developed by the International Organization for Standardization (ISO) to standardize how network devices and software communicate. 

### The 7 Layers of the OSI Model (Top to Bottom)

### 7. Application Layer

* Function: Acts as the direct interface between user-facing software and the network.  
* Key Tasks: Provides network services to applications like web browsers and email clients. 
* Protocols: HTTP/HTTPS, SMTP, FTP, DNS. 

### 6. Presentation Layer

* Function: Translates, formats, and encrypts data so the application layer can understand it. 
* Key Tasks: Data compression, decompression, encryption, and decryption (e.g., SSL/TLS). 
* Formats: JPEG, GIF, JSON, SSL/TLS. 

### 5. Session Layer

* Function: Establishes, maintains, synchronizes, and terminates communication sessions between applications.
* Key Tasks: Session control, authentication, and checkpoint recovery. 
* Protocols: NetBIOS, RPC, NFS. 

### 4. Transport Layer

* Function: Ensures end-to-end data delivery, segmentation, and error checking between hosts.
* Key Tasks: Breaks data into segments, manages flow control, and handles retransmission of lost packets.
* Protocols: TCP (reliable, connection-oriented) and UDP (fast, connectionless). 

### 3. Network Layer

* Function: Handles logical addressing and determines the best physical path (routing) across multiple networks.
* Key Tasks: Packet forwarding, source-to-destination routing, and handling IP addresses.
* Protocols: IPv4, IPv6, ICMP, IPsec. 

### 2. Data Link Layer

* Function: Manages node-to-node delivery and error correction on the same local network segment.
* Key Tasks: Frames packets into data frames, uses MAC addresses for local delivery, and handles error detection.
* Sub-layers: LLC (Logical Link Control) and MAC (Media Access Control); includes ARP.
* Protocols/Media: Ethernet, Wi-Fi (802.11).

### 1. Physical Layer

* Function: Transmits raw bitstreams (1s and 0s) over physical hardware and media.
* Key Tasks: Converts bits into electrical voltages, radio waves, or light pulses and defines pinouts/cables.
* Hardware: Ethernet cables, fiber-optic cables, hubs, repeaters, network interface cards (NICs).
