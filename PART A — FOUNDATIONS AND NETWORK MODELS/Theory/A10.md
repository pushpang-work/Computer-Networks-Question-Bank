## Question 

Describe the TCP/IP model and map its layers to the OSI model.

## Answer 

The TCP/IP Model (Transmission Control Protocol/Internet Protocol) is a practical 4-layer framework that powers real-world communication on the internet. 

### Layers of the TCP/IP Model

* Application Layer (Process/Application): Provides network services directly to end-user applications (such as web browsers or email clients) and handles tasks like data formatting, encryption, and session management. 
* Transport Layer (Host-to-Host): Manages end-to-end communication, error checking, flow control, and reliability using protocols like TCP (reliable stream) and UDP (fast datagram). 
* Internet Layer (Network): Handles logical addressing, packet formation, and routing across independent networks using IP (Internet Protocol) and ICMP. 
* Network Access Layer (Link / Network Interface): Manages the physical transmission of data, hardware addressing (MAC addresses), and framing over local media like Ethernet or Wi-Fi.


### Mapping TCP/IP Layers to the OSI Model
The 7-layer OSI (Open Systems Interconnection) Model is a theoretical reference framework. Its functions correspond to the TCP/IP stack as follows: [1, 2, 6, 7] 

| TCP/IP Model (4 Layers) | OSI Model (7 Layers) | Primary Functions & Examples |
|---|---|---|
| Application Layer | • Layer 7: Application Layer • Layer 6: Presentation Layer • Layer 5: Session Layer | Combines user interface, data translation, encryption (TLS), and session dialog control. Examples: HTTP, DNS, FTP. |
| Transport Layer | • Layer 4: Transport Layer | Manages end-to-end data segmentation, port numbers, and delivery reliability. Examples: TCP, UDP. |
| Internet Layer | • Layer 3: Network Layer | Handles logical IP addressing and routing packets across routers. Examples: IP, ICMP, ARP. |
| Network Access Layer | • Layer 2: Data Link Layer • Layer 1: Physical Layer | Manages physical media, binary bit signals, cables, and hardware MAC addressing. Examples: Ethernet, Wi-Fi. |
