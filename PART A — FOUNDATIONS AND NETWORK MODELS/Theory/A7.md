## Question 

Explain simplex, half-duplex, and full-duplex communication.

## Answer 

Simplex, half-duplex, and full-duplex are the three basic ways data flows between devices on a communication network, categorized by direction and timing. 

### 1. Simplex Communication

* Direction: One-way (unidirectional) only.
* How it works: The sender can transmit data, but the receiver can only listen and cannot reply or send data back. The entire channel bandwidth goes to that single direction. 
* Common Examples:
* Keyboard sending a signal to a monitor.
   * Television and radio broadcasting.
   * Public announcement (PA) systems. 

### 2. Half-Duplex Communication

* Direction: Two-way (bidirectional), but not at the same time.  
* How it works: Both devices can send and receive data, but only one device can transmit at any given moment. When one talks, the other must wait and listen, then switch roles. It uses a single shared channel. 
* Common Examples:
* Walkie-talkies (using "push-to-talk").
   * Police and emergency radio dispatchers.
   * Early/legacy Ethernet networks. 

### 3. Full-Duplex Communication

* Direction: Two-way (bidirectional) simultaneously. 
* How it works: Both connected devices can send and receive data at the exact same time without waiting. It typically uses two separate channels or frequency-division/time-division multiplexing. This mode offers the highest performance and throughput. 
* Common Examples:
* Telephone calls and mobile phones.
   * Video conferencing and VoIP (Voice over IP).
   * Modern high-speed Ethernet networks. 

### Quick Comparison Table

| Feature | Simplex | Half-Duplex | Full-Duplex |
|---|---|---|---|
| Data Direction | One direction only | Both directions (one at a time) | Both directions (simultaneously) |
| Channel Usage | Single channel | Single shared channel | Two channels or simultaneous paths |
| Speed / Performance | Lowest | Moderate | Highest |
| Hardware Cost | Lowest / Simplest | Moderate | Highest / Most complex |
| Example | Keyboard / TV Broadcast | Walkie-Talkie | Telephone / Video Call |
