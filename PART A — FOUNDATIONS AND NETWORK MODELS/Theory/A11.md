## Question 

What are encapsulation and decapsulation? Trace a web request through the protocol layers.

## Answer 

Encapsulation is the sender-side process of wrapping raw data with protocol-specific headers (and sometimes trailers) as it moves down the network stack. Decapsulation is the receiver-side reverse process of stripping away those headers and trailers as the data moves up the network stack to recover the original payload. 

### Step-by-Step Trace of a Web Request

When you type a URL into a browser and send an HTTP request, the data flows down through the TCP/IP stack at your computer, hops across routers, and flows back up the stack at the web server. 

### 1. Sender Side: Encapsulation (Down the Stack)

* Application Layer (Layer 7):
    * The browser generates the original application data, such as an HTTP GET request message (GET /index.html HTTP/1.1). 
* Transport Layer (Layer 4):
    * The HTTP message is handed to TCP (or UDP).
   * A TCP header is prepended, adding source and destination port numbers (e.g., port 443 for HTTPS) and sequence/acknowledgment numbers.
   * This package is now called a Segment. 
* Network / Internet Layer (Layer 3):
    * The TCP segment is passed to IP.
   * An IP header is prepended, containing the source IP address and destination IP address of the web server.
   * This package is now called a Packet (or IP datagram). 
* Data Link Layer (Layer 2):
    * The IP packet is wrapped into a frame format (e.g., Ethernet).
   * A Data Link header (containing source and destination MAC addresses) and a Frame Check Sequence (FCS) trailer for error detection are added.
   * This package is now called a Frame. 
* Physical Layer (Layer 1):
    * The frame is converted into raw bits (electrical voltages, light pulses, or radio waves) and transmitted across the physical medium. 

### 2. Intermediary Routers (Hop-by-Hop Processing)

* As the frame hits a router along the path, the router performs partial decapsulation and re-encapsulation:
    * It strips the Layer 2 Ethernet frame header/trailer.
   * It inspects the Layer 3 IP header to read the destination IP address and consults its routing table.
   * It strips the old MAC addresses and wraps the packet in a new Layer 2 frame addressed to the next-hop router or destination server. (Note: IP addresses and TCP ports remain unchanged end-to-end). 

### 3. Receiver Side: Decapsulation (Up the Stack)

* Physical Layer (Layer 1):
    * The web server's network interface card (NIC) receives the physical signals and converts them back into a stream of bits. 
* Data Link Layer (Layer 2):
    * The NIC verifies the MAC address and FCS trailer, strips the Ethernet header and trailer, and passes the resulting Packet up to the network layer.
* Network / Internet Layer (Layer 3):
    * The server checks the IP header to confirm the destination IP matches itself, strips the IP header, and passes the resulting Segment up to the transport layer.
* Transport Layer (Layer 4):
    * The TCP layer reads the port number, handles any sequence reassembly or acknowledgments, strips the TCP header, and passes the raw payload up to the application layer. 
* Application Layer (Layer 7):
    * The web server application (e.g., Nginx or Apache) reads the original HTTP request and processes it.
