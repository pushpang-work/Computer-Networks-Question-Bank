## Question 

Define protocol, service, interface, frame, packet, segment, datagram, and PDU.

## Answer 

A set of standard rules, formats, and procedures that allows electronic devices to communicate and exchange data across a network. 

* Protocol: A formal set of rules and conventions that determine how data is transmitted, formatted, received, and processed across a network (e.g., HTTP, TCP, IP).
* Service: A capability or set of functions provided by one layer of a network architecture to the layer directly above it (e.g., reliable connection delivery or naming resolution).
* Interface: A boundary that defines how two adjacent layers in a network stack (or two separate hardware/software components) interact and pass data to each other.
* Frame: The Protocol Data Unit (PDU) operating at the Data Link Layer (Layer 2), which encapsulates a packet with a header and trailer (including MAC addresses and error-checking bits) for node-to-node physical delivery.
* Packet: The PDU operating at the Network Layer (Layer 3), which contains source and destination IP addresses and routing control info to traverse multiple networks. 
* Segment: The PDU operating at the Transport Layer (Layer 4) when using connection-oriented, reliable protocols like TCP, including port numbers and sequence numbers. 
* Datagram: The PDU operating at the Transport Layer (Layer 4) when using connectionless, lightweight protocols like UDP (or broadly used as a synonym for a self-contained packet at the network layer). 
* PDU (Protocol Data Unit): A generic term representing the specific unit of data containing both control information (headers/trailers) and user payload passed down or up a given layer of the OSI or TCP/IP model. 

### Data Encapsulation Flow Across Layers

* Application / Session / Presentation: Data (Message)
* Transport Layer: Segment (TCP) or Datagram (UDP)
* Network Layer: Packet
* Data Link Layer: Frame
* Physical Layer: Raw Bits
