## Question 

Compare wired and Wi-Fi performance in your own environment using a consistent test method; document limitations.

## Answer 

Wired (Ethernet) connections deliver higher throughput, lower latency, and zero signal interference compared to Wi-Fi. 

### Performance Comparison

| Metric | Wired (Gigabit Ethernet) | Wireless (Wi-Fi 6) |
|---|---|---|
| Throughput (Speed) | Near-maximum line rate (e.g., 370–940+ Mbps) | Lower effective throughput (e.g., 210–600 Mbps) |
| Idle Latency (Ping) | Ultra-low (sub-1 ms to 2 ms) | Higher and more variable (5 ms to 15+ ms) |
| Jitter (Variation) | Minimal to none (<1 ms) | Noticeable fluctuation (4 ms to 9+ ms) |
| Packet Loss | Near 0% under normal loads (0.8% or lower) | Higher risk from air congestion (1% to 3%+) |

### Consistent Test Method
To benchmark performance fairly between wired and Wi-Fi modes on the same client machine:

   1. Isolate the Environment: Pause active background downloads, cloud backups, and close streaming apps. Disable any active VPN services to prevent routing overhead from skewing baseline numbers.
   2. Establish the Wired Control: Connect a laptop or desktop directly to the primary router using a certified Cat5e or Cat6 Ethernet cable. Verify the network interface card negotiates a full link speed (e.g., 1 Gbps). Run a standardized tool (such as Ookla Speedtest or iperf3) three times and record average download, upload, ping, and jitter.  
   3. Test Wi-Fi Near the Router: Disconnect the Ethernet cable, enable Wi-Fi 6 (802.11ax), and stand within 5 to 10 feet of the router with a clear line of sight. Run the identical test sequence three times. 
   4. Test Wi-Fi at Distance: Move the test device to a typical remote room separated by walls or floors. Repeat the test sequence to document attenuation and signal drop-off. 

### Documented Limitations

* Hardware Bottlenecks: Older Ethernet cables (like unshielded or damaged 4-wire leads) can artificially cap wired speeds at 100 Mbps. Similarly, old network interface cards (NICs) or router ports limit maximum throughput. 
* Radio Frequency Interference: Wi-Fi performance changes dynamically based on overlapping radio channels from neighboring networks, Bluetooth devices, microwaves, and physical barriers like concrete walls or metal studs. 
* Client Device Constraints: Internal antenna configurations, power-saving modes, and driver implementations on smartphones or thin laptops restrict wireless speeds well below theoretical router maximums. 
* ISP / Backbone Variability: External internet congestion or server routing changes during testing can introduce noise that looks like local network variance unless using a local loopback tool like iperf3 on a local server.
