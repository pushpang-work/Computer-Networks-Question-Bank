## Question 

Create an OSI-to-TCP/IP mapping table with example protocols at each layer.

## Answer 

The OSI 7-layer model maps to the 4-layer (RFC 1122) and 5-layer (Cisco) TCP/IP models as follows: 

| OSI Layer | OSI Layer Name | TCP/IP 4-Layer Model | TCP/IP 5-Layer Model | Example Protocols |
|---|---|---|---|---|
| Layer 7 | Application | Application | Application | HTTP, DNS, SMTP, FTP |
| Layer 6 | Presentation | Application | Application | TLS, SSL, JPEG, ASCII |
| Layer 5 | Session | Application | Application | NFS, NetBIOS, RPC |
| Layer 4 | Transport | Transport | Transport | TCP, UDP |
| Layer 3 | Network | Internet | Network | IPv4, IPv6, ICMP |
| Layer 2 | Data Link | Link / Network Access | Data Link | Ethernet, Wi-Fi, PPP |
| Layer 1 | Physical | Link / Network Access | Physical | Copper cables, Fiber optics, Radio frequencies |
