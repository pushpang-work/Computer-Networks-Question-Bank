## Question 

Build a small star topology in a network simulator with at least four hosts and one switch.

## Solution 


To build a star topology, you will connect multiple independent hosts directly to a single central network switch. Here is a step-by-step guide to building this setup using Cisco Packet Tracer, one of the most common and accessible network simulators.

### 🛠️ Required Components

* 1 Central Switch: Generic or 2960 Switch
* 4 End Devices: PCs or Laptops
* 4 Cables: Copper Straight-Through cables

### 📋 Step-by-Step Implementation

### 1. Place the Hardware

* Open your network simulator.
* Navigate to End Devices in the bottom-left menu and drag 4 PCs onto the workspace.
* Navigate to Network Devices > Switches, select the 2960 Switch, and drag it to the center of your 4 PCs.

### 2. Connect the Devices

* Select the Connections tool (the lightning bolt icon).
* Choose the Copper Straight-Through cable (solid black line).
* Click on PC0, select FastEthernet0, and drag the cable to the Switch. Select FastEthernet0/1.
* Repeat this process for the remaining three PCs, connecting them to available ports on the switch (e.g., FastEthernet0/2, FastEthernet0/3, and FastEthernet0/4).

### 3. Configure IP Addresses
To allow the hosts to communicate, you must assign them IP addresses on the same subnet:

* Click on PC0 to open its settings configuration menu.
* Go to the Desktop tab and click on IP Configuration.
* Set the IP address and Subnet Mask as shown in the table below.
* Repeat this step for all 4 PCs.

| Device Name | IP Address | Subnet Mask |
|---|---|---|
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |
| PC2 | 192.168.1.3 | 255.255.255.0 |
| PC3 | 192.168.1.4 | 255.255.255.0 |

### 🧪 Verifying the Connectivity

   1. Click on PC0 and open the Command Prompt from the Desktop tab.
   2. Type ping 192.168.1.4 and press Enter to test the connection to PC3.
   3. If successful, you will see four lines reading: "Reply from 192.168.1.4: bytes=32 time=..."
