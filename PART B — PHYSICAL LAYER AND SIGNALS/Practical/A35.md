## Question 

Calculate transmission delay for three file sizes over three link speeds and present a table.

## Answer 

Transmission delay is the total amount of time required to push all of a file's bits into the communication medium. It is calculated using the following formula: 

$\text{Transmission Delay} = \frac{\text{File Size (in bits)}}{\text{Link Speed (in bits per second)}}$

In networking, file sizes are typically measured using binary notation ($1\text{ KB} = 1,024\text{ Bytes}$), while link speeds use decimal notation ($1\text{ Mbps} = 1,000,000\text{ bps}$). Using these standard conventions, here is the matrix demonstrating transmission delays across three distinct file sizes and three common network link speeds: 

### Transmission Delay Comparison Table (in seconds)

| File Size \ Link Speed | 10 Mbps ($10^7$ bps) | 100 Mbps ($10^8$ bps) | 1 Gbps ($10^9$ bps) |
|---|---|---|---|
| 100 KB ($819,200$ bits) | 0.081920 s | 0.008192 s | 0.000819 s |
| 10 MB ($83,886,080$ bits) | 8.388608 s | 0.838861 s | 0.083886 s |
| 1 GB ($8,589,934,592$ bits) | 858.993459 s | 85.899346 s | 8.589935 s |
