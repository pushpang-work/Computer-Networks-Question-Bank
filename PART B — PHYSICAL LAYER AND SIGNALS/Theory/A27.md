## Question 

Compare synchronous and asynchronous transmission.

## Answer 

Synchronous transmission sends data continuously using a shared clock signal, while asynchronous transmission sends data in discrete bytes or characters with start and stop bits. 

### Key Differences

* Clock Signal:
    * Synchronous: Uses a single, shared common clock signal to synchronize the sender and receiver.
   * Asynchronous: Uses separate internal clocks; does not require a shared external clock signal. 
* Data Unit:
    * Synchronous: Transmits data in large continuous blocks or frames.
   * Asynchronous: Transmits data one byte or character at a time. 
* Framing Bits:
    * Synchronous: Does not use start and stop bits, which lowers per-bit overhead.
   * Asynchronous: Wraps each byte/character with start and stop bits (and sometimes parity bits). 
* Speed and Efficiency:
    * Synchronous: Faster, more efficient, and has lower latency for high-volume streams.
   * Asynchronous: Slower, has higher overhead, and leaves idle gaps between data transmissions.  
* Hardware Cost:
    * Synchronous: More complex and expensive to implement.
   * Asynchronous: Simpler and more cost-effective.  
* Examples:
    * Synchronous: Video conferencing, telephonic conversations, and live chat rooms.
   * Asynchronous: Emails, discussion forums, and keyboard inputs.
