## Question 

How are bit rate and baud rate related? Give an example where they differ.

## Answer 

Bit rate and baud rate are connected by how much data each signal change carries:

<pre> Bit Rate = Baud Rate × Number of Bits per Symbol</pre>

* Bit rate is the total number of individual binary digits (0s and 1s) transmitted per second, measured in bps (bits per second).
* Baud rate is the number of distinct signal changes or symbols transmitted per second, measured in baud (or symbols/second). 

They are only equal when each symbol represents exactly one bit of data (such as in simple binary signaling).

### Example Where They Differ (16-QAM Modulation)

* Baud Rate: A system transmits 1,000 symbols per second ($1,000$ baud).
* Bits per Symbol: Using 16-QAM (Quadrature Amplitude Modulation), each symbol can represent 4 bits of data ($2^4 = 16$ states).
* Bit Rate Calculation: 
    
<pre> Bit Rate = 1,000 symbols/sec × 4 bits/symbol = 4,000 bps </pre>

In this scenario, the baud rate is 1,000 baud, while the bit rate is 4,000 bps (four times higher).
